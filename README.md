# Video Lab

Cloud video generation with [Remotion](https://www.remotion.dev/).

This repository contains a first vertical sample composition:

- Resolution: 1080 × 1920
- Duration: 10 seconds
- Frame rate: 30 FPS
- Output: MP4 (H.264)

## Render in GitHub

1. Open the **Actions** tab.
2. Select **Render video**.
3. Click **Run workflow**.
4. Open the completed run.
5. Download the `laboratory-42-video` artifact.

The workflow also runs automatically when files in `src/`, `package.json`, or the workflow itself change.

## Local development (optional)

Requires Node.js 20 or newer.

```bash
npm install
npm run studio
```

## Notes

The MP4 is generated by GitHub Actions and stored as a temporary workflow artifact. It is not committed to the repository.
